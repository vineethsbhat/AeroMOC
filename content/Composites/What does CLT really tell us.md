First some basic things to know :
1. Ply angles are always given relative to the x-axis of the laminate
2. First ply in the sequence is the ply which is first inserted into the tool
3. Mid-Plane Symmetry : Symmetric about the middle plane of the laminate, e.g., (0/90)s
4. Balanced Laminate : For every $+\alpha$ ply there is a $- \alpha$ ply
5. Length plane symmetry : Feasible only for laminates that have 0 and 90 deg plies
