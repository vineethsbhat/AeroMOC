Fiber Types :
1. Natural Fibers - Organic and Inorganic 
2. Synthetic Fibers - Organic and Inorganic

Matrix Types :
1. Thermoset : As the name suggests once the matrix is cured, it is set in place. 
2. Elastomers : Elastic in nature, elastic like behaviour, e.g., silicone, rubber
3. Thermoplastics : Plastics that can be reformed and shaped upon heating, e.g., PET, PEEK, PA

>Resin Selection is based on :
>1. Shrinkage and cure behaviour
>2. Heat resistance, Fire retardant properties
>3. Adhesive properties
>4. Viscosity
