Composite airframe :

- It is possible to replace, part for part, an aluminium airframe by an equivalent composite airframe.
- But this would not make full use of composite capabilities and result in a very high fabrication cost because the different parts are made separately and assembled together with fasteners
- When a composite design matches closely with aluminium then its called as 'Black Aluminium'. It is quasi-isotropic in nature and there is no attempt to make full use of composite properties

In structures when we talk about efficiency we are typically referring it to the lowest weight given a set of applied loads. But it can be any combination of desired attributes of a structure like weight, cost, natural frequency etc.

Parts used are classified into part families :

a. Skin : 2D thin structure covering outside of fuselage or wing, usually single curvature 
b. Stringers/stiffeners : 1D beam like structures
c. Frames/Bulkhead : 2D ring like structures placed at equal intervals along the fuselage
d. Beams : 2D plate like structures that carry bending loads
e. Spars : Beams used along the length of the wing
f. Ribs : 2D plate like structures placed in equal intervals along the length of the wing
g. Fittings : 3D structures connecting parts
h. Fairings : 2D structure but with a compound or more than one curvature
